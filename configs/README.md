# Configuraciones de ejemplo

Estos dos archivos son las configuraciones **reales** de las corridas descritas en
`docs/VALIDACION.md` (primates) y `docs/MURCIELAGOS.md` (murciélagos). Sirven como
referencia de qué opciones existen y cómo se combinan, pero **no se ejecutan tal cual**:
sus rutas (`../../tiff_primates_binarios`, etc.) apuntan a datos que no se distribuyen
con la librería.

Para empezar un proyecto propio, genera una plantilla comentada y vacía:

```bash
spatialcom init mi_proyecto
```

Qué capa hace falta en cada carpeta, de dónde bajarla y en qué estado debe llegar:
[`docs/DATOS.md`](../docs/DATOS.md).
